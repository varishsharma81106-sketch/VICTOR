## What These Words Actually Mean

*A plain translation with no drift. Each point below maps directly to something Varish said.*

**1. Physical object first.**
"Like a calculator, like a mouse, like a physical object." Victor is a device. The AI is embedded in it. Not an AI product that has a device attached. The physical form is the product; the AI is one system inside it.

**2. Domain specialists feed a central reasoner.**
"Victor has multiple ML models inside it for each sort of things" and "it all unifies to a single model, which is a reasoning model." This is a hierarchy: per-domain models (UV, signal, visual, etc.) compress raw sensor data into structured inferences, which then feed one central reasoning model. Not self-improvement — a reasoning hierarchy. Varish confirmed this explicitly when the word "self-improving" was used incorrectly: *"The word came out to be wrong. It was the upper layer of the pretrained models that we have created a hierarchy of reasoning."*

**3. 90% capable offline.**
Not a degraded mode. The device carries pre-trained models and dataset flows on local storage. Offline is the default reliable state. Internet adds capability, it does not enable capability.

**4. Masked memory graph.**
"It stores in a whole memory way." Not flat files. Not a chat log. Every experiment is connected to others through relations. But — critically — memories are masked. The relational anchors between memories stay live. The full content of a specific memory only surfaces when the user explicitly calls it. This is the most original idea in the original conception and it remains the most original idea in the current implementation.

**5. Two separate security features.**
Varish described two distinct things that later documents merged into one:
- A security system that prevents hacking and intrusion — "a sovereign cybersecurity model inside of it, which is an individual AI cybersecurity system for each device."
- A separate user-controlled switch — "which lets the user decide what the AI has to publish."
These are not the same feature. The first is defensive. The second is sovereign. Both matter.

**6. Not for the general public.**
"This is not for the general public, although general public could use the AI versions, but the toolkit of itself isn't for the general public. It is for the research and the purposes of the industry." Two tiers: the physical toolkit for research/industrial operators; a lighter AI version for general public.

**7. The motivating scenario is survival, not efficiency.**
"A person who is trapped in vast of space and in any planet... he has to find out to survive the needs for his environment." This is the emotional core. Not "make research more organized." A person alone, in a hostile environment, needing the device to understand their surroundings to survive. The real-world translation is research/industrial operators in hazardous or remote environments — not office researchers.

**8. Modular deployment, not fixed handheld.**
"You even send it to the Voyager 1." "For a prototype, maybe less." The "insane radius" comment was not a claim about sensor physics — it was a claim about deployment scale. The device is modular. It can be handheld in a field. Mounted in a submarine. Embedded in a spacecraft. The intelligence layer adapts to whatever platform carries it.

## What Earlier AI Sessions Got Wrong

*Recorded here so future sessions do not repeat the same mistakes.*

**Mistake 1: Inverted the physical/AI relationship.**
PRD v4.6 Section 1: "Victor is not a device. Victor is not software... Victor is the principle." This is philosophically interesting but it quietly moves away from "it's a physical object, like a calculator." The principle framing is useful for software development. It should never replace the physical object framing when describing what Victor is to someone new.

**Mistake 2: Replaced the survival scenario with research efficiency.**
The ELN-era analysis documents framed the problem as "researchers' work is fragmented across notebooks." That is true but it is not Varish's framing. His framing: a person alone, who needs to understand their environment to survive. The research efficiency framing is a softened version that loses the stakes.

**Mistake 3: Conflated the two security features.**
Multiple documents merged "prevent hacking" and "user controls what gets published" into a single "sovereignty" principle. They are separate. One is a defensive system. One is a user right.

**Mistake 4: Misread "self-improvement" as weight updates.**
Varish's "it tries to learn itself and enhance itself" referred to the reasoning hierarchy — domain models feeding a central reasoner that builds understanding from accumulated knowledge. Not autonomous weight updates. He corrected this explicitly and it should not resurface.

**Mistake 5: Dropped the masked memory graph as a detail.**
The masked memory graph — relational anchors live, full content hidden until called — is the most original idea in the entire conception. Early analysis documents treated it as a minor technical detail. It is the differentiating mechanism. Everything else has analogues in existing products. This specific mechanic applied to sovereign sensor intelligence does not.
