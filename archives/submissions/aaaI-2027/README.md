# AAAI-27 Submission Archive

Materials from the AAAI 2027 paper submission (submitted July 22, 2026).

## Structure

- `paper-22july/` — the submission copy: anonymous abstract, LICENSE (MIT for submission), reproducibility checklist, references.bib (submission copy), and the compiled `victor_aaai27.pdf`. Also the submission report.
- `author-kit/` — the official AAAI-27 Author Kit (`aaai2027.sty`, `aaai2027.bst`, `aaai2027.bib`) plus compiled outputs: anonymous submission PDF/TeX, camera-ready PDF/TeX, reproducibility checklist PDF/TeX, Word versions, and Figures.
- `aaai.bst`, `aaai.sty` — fallback style files (superseded by the aaai2027 variants for the actual submission).
