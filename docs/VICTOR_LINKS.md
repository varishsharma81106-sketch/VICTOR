## Obsidian Setup

1. Open Obsidian
2. Open folder as vault: `docs/`
3. Go to Settings → Files & Links
4. Enable "Use [[Wikilinks]]"
5. Enable "Shorten links to headings"
6. Go to Settings → Core plugins
7. Enable "Graph view"
8. Open Graph view to see bidirectional links
