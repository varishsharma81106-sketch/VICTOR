Victor inside a machine

Ask is bulk retrieval: five chunks arrive by cosine distance and the model explains whatever it was handed. Here the machine is handed referral points instead — a line per memory saying what it is, never what it says — and it spends a budget one handle at a time, stating a reason for each. Masked memory is a door with a log, not a hole in the context: the machine can knock, and the refusal is part of the record.

The masked memory graph
